Box Guide
Box 공통규칙
  1. class 명 :[color]-box-[여백 size]
  2. [color 정의]
    • white: background-color : #FFF (GRAY00)
    • gray: background-color : #F5F5F5
    • gray-line: border : 1px solid #E5E5E5
  3. [여백 size 정의]

    : 박스별 사이즈 여백 상이 (* 박스별 size 여백 필요에 따라 추가되어 공통 규칙 없음)

[color]-box-lg
[color]-box-lg : 여백 20px
