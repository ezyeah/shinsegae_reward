Row List Guide
Row List 공통 규칙
  • ul.row-list > li.row-item의 구조를 가진다.
  • 간격별 네이밍 정의
    • ul.row-list-lg : row-item + row-item 사이의 간격 30px
    • ul.row-list-md : row-item + row-item 사이의 간격 20px
    • ul.row-list-sm : row-item + row-item 사이의 간격 16px
    • ul.row-list-xs : row-item + row-item 사이의 간격 12px
  • .has-line : row-item사이에 라인이 있는 경우 ul.row-list-[size]에 멀티 클래스로 추가한다.
