# Goods Group 공통 규칙
  • 기본 구조

    goods-group
    > .label
    > .goods > .val > .unit

  • font size 구분하여 goods-group-{$size} class 사용 필요
    • goods-group-xs font-size: 12px
    • goods-group-sm font-size: 13px
    • goods-group-md font-size: 14px
    • goods-group-lg font-size: 15px
    • goods-group-xl font-size: 16px
    • goods-group-2xl font-size: 20px
    • goods-group-3xl font-size: 22px
    • goods-group-4xl font-size: 32px
