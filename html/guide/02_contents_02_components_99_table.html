Table 공통 규칙
  • table 태그를 사용하는 테이블의 경우, caption 제목 입력 필요(나머지 caption th 내용 수집하여 스크립트로 처리)
  • [테이블 공통 적용 클래스]
    • .tbl-info.info-right : 텍스트 우측 정렬
    • 추가 예정 : -
tbl-wrap
  1. tbl-wrap
    • tr: 간격 10px
    • th: font-size: 13px / font-weight : 500 / color : #888
    • td: font-size: 13px / font-weight : 500 / color : #888
    • 폰트컬러 변경이 필요할 경우#Typography참고하여 적용한다.
